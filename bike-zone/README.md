# BIKE ZONE — free-host preview

This folder is a static, bilingual Arabic/English BIKE ZONE website prepared for GitHub Pages at `https://afawzy2611.github.io/bike-zone/`.

- Arabic RTL default; English LTR toggle.
- Responsive layout and accessible navigation.
- Direct phone and WhatsApp links; inquiry form intentionally opens WhatsApp and does not collect/store submissions on this static host.
- Includes robots.txt, XML sitemap, canonical URL, and JSON-LD business data.
- Images still load from the existing public Floot CDN; keep the original websites live until asset availability and the hosted page are verified.

This is a separate preview and does not replace `https://bike-zone.floot.app` or WebsitePublisher.
